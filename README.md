# Elite Wear

Professional responsive e-commerce storefront for Elite Wear — men's fashion and accessories in Pakistan.

## Included
- Premium responsive homepage
- Clothing, footwear, watches, accessories and perfume categories
- Featured products and filters
- WhatsApp ordering with Elite Wear WhatsApp number
- Search modal
- Local cart counter using browser storage
- Mobile navigation
- SEO metadata and social preview metadata
- Nationwide Pakistan delivery and COD messaging

## Run locally
Open `index.html` in a browser.

## GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will provide the live Pages address after deployment.
